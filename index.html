速用流程

  1. 自己设备上编辑，数据先存在浏览器本地。
  2. Cloudflare 配好后点同步，写入你的云端 KV。
  3. 客户电脑用无痕窗口打开网页版，登录 token 后拉取。
  4. 离开时退出同步并关闭窗口。

同步设置

第一版已预留 Cloudflare Pages Functions + KV 同步接口。部署后配置环境变量即可启用云同步。

未连接云同步，本地功能可正常使用。
